Overview

THE READ Athletics (“THE READ”) is a recruiting-intelligence project. This draft describes how we intend to handle information collected through this website.

What this website collects today

This website is a static site. The request forms do not send data to a server or database. When you submit a form, your own email app opens with a pre-filled message to hello@thereadathletics.com; only what you choose to send reaches us.

Information you send us

If you email us, we receive the details you include (for example name, email, graduation year, sports, positions, institution). We use it to respond to your request and to evaluate access to THE READ.

Minors

Athletes may be under 18. We intend to ask for parent or guardian involvement where appropriate, limit the data collected about minors, and never publish minors’ contact details. See the security and privacy page.
